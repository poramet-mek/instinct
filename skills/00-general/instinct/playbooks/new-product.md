# Playbook: New Product

Use when starting a new product, defining a commercial bundle, or setting up repo standards.

1. `instinct-business` — Define problem, Buyer vs User, market benchmark, 2+ pricing/packaging models, remote supportability, and draft/review BRD.
2. `grilling` — Stress-test open product/technical decisions via design-tree rounds.
3. `instinct-plan` — Produce Requirement Record, Scope/Non-goals, constraints, task breakdown, and realistic estimates.
4. `instinct-standards` — Establish `ARCHITECTURE.md`, `CODING_STANDARDS.md`, folder layout, and initial ADRs.
