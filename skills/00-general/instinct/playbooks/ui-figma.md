# Playbook: UI Figma

Use for UI-focused tasks driven by Figma designs.

1. `git-workflow` — Branch `feat/<name>` from `develop`.
2. `instinct-figma` — **Mode A (Implement):** fetch one Frame/Component Node ID at a time and build UI + states.
3. `instinct-figma` — **Mode B (Visual Parity):** compare live UI screenshot against Figma and fix discrepancies.
4. `verify` — Run UI/component tests and interactive checks.
5. `unslop` — Clean diff and comments.
6. `instinct-review` — Review diff before PR.
