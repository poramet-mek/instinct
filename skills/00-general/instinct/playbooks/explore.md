# Playbook: Explore (Read-Only)

Use when onboarding to an unfamiliar codebase or scoping feasibility and effort before committing to build.

1. `instinct-ask` — Run **Full Repo Inventory** (screens, features, DB tables, config) or **Single-Feature Flow** for targeted scoping.
2. `instinct-plan` — Summarize feasibility, affected modules, risks, and rough time/effort estimate.

Do not edit production files in this playbook.
