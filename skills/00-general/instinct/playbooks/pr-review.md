# Playbook: PR Review (Read-Only)

Use when reviewing a teammate's PR or your own branch before merge.

1. `instinct-ask` — *(If needed)* Trace affected callers/flows to verify blast radius.
2. `instinct-review` — Inspect diff against `WILL BREAK`, `WILL COST`, `WILL ROT`, and `PROJECT RULE`, ending in `SHIP` / `SHIP WITH FIXES` / `DO NOT SHIP`.

Do not edit files in this playbook.
