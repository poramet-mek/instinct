# Unslop

Inspect `git diff` (or target source files) and strip away everything that does not earn its keep.

- **Skip generated, vendored, and build files:** Never inspect or edit generated outputs (`*.g.*`, `*.freezed.*`, `*.pb.*`, files with `GENERATED CODE` / `Autogenerated` headers), lockfiles, or build/dependency dirs (`build/`, `.dart_tool/`, `node_modules/`, `dist/`).

## Checklist

1. **Subtract before you add:** Delete dead code, unused imports/variables, debug logs, and speculative abstractions.
2. **Remove AI tells:** Strip defensive try/catch blocks that swallow errors, redundant null checks on guaranteed types, and over-engineered single-use helpers.
3. **Code Comment Standards:**
   - Comment **why** (non-obvious invariants, trade-offs, external quirks), never **what** the code already says.
   - Delete comments that restate the code line-by-line.
   - Keep doc comments concise (<= 3 lines) and inline comments brief (<= 2 lines); put long rationale in an ADR/doc link.
4. **Sync Living Docs:** Remove or update stale doc links, `CONTEXT-MAP.md`, `ARCHITECTURE.md`, or `docs/concepts/` references affected by moved/deleted symbols or packages.
5. **Re-run tests** after cleanup to confirm nothing broke.
