# Release Packet: v2.0.0

## Version Matrix

| Component | Version | Notes |
|---|---|---|
| `instinct` | `2.0.0` | Node.js `>=20`, zero runtime dependencies |
| Target Agents | `claude`, `codex`, `agy`, `gemini` | Installed via `bin/instinct.js` with managed marker |
| Skills / Playbooks | 22 skills / 12 playbooks | All skills `<= 80` lines |

## Change Summary & Impact

- **Summary:** Complete v2.0.0 rewrite from `v1.1.3` to 22 lean atomic SDLC skills, 12 orchestrator playbooks, and a cross-agent CLI installer (`bin/instinct.js`). Includes `instinct-handoff`, `retro`, `instinct-concept`, and `instinct-manual` (`user-manual-for-<slug>.md` with discovery, screenshot capture, troubleshooting, and target-persona review).
- **Affected Users / Systems:** Developers using Claude Code, Codex, Antigravity, or Gemini CLI.
- **Risk Level:** Low–Medium. User-only skills use `disable-model-invocation: true` (0 idle token overhead), and `uninstall --apply` only removes managed skill directories.

## Verification Evidence

- **Unit & CLI Tests (`npm test`):** 5/5 tests passing (22 skills frontmatter/line-limit discovery, 12 playbooks check, dry-run install, `install --apply` & `uninstall --apply` preserving custom skills, `_npx`/`node_modules` copy-mode regression test, CLI flag validation).
- **Skill Discovery (`node bin/instinct.js list`):** Verified all 22 skills listed.
- **Install Verification (`node bin/instinct.js install --apply`):** Verified installation across all 4 targets (`claude`, `codex`, `agy`, `gemini`).
- **Code Review (`/instinct-review`):** Verdict `SHIP` after fixing `_npx`/`node_modules` ephemeral symlink handling.

## Rollout & Rollback Plan

1. **Rollout:**
   - Review and merge PR (`feat/v2-clean-slate` -> `main`).
   - Tag `v2.0.0` on `main` and push tag.
   - Run `npx github:poramet-mek/instinct install --apply` (or `node bin/instinct.js install --apply` locally) on target workstations.
2. **Rollback:**
   - Run `node bin/instinct.js uninstall --apply` to remove v2.0.0 managed skills.
   - Revert/checkout `v1.1.3` (`git checkout v1.1.3`) if legacy setup is needed.
